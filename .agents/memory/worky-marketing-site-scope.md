---
name: Worky marketing site separation
description: The public Worky landing must be hosted separately from the marketplace app.
---

Build the Worky marketing landing as a standalone site in its own Replit project with its own domain and publishing lifecycle. Do not add it as a route or artifact to the marketplace project.

**Why:** The user explicitly chose a separate project and domain so the public marketing site is not part of the platform; Replit publishes all artifacts in a project together.

**How to apply:** If asked to continue this landing from the marketplace repl, first move to or create the separate project. Reuse Worky's existing brand identity and link back to the platform only after its URL is known.
