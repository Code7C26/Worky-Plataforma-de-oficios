---
name: Mobile tab visual system
description: Shared visual direction for Worky's main mobile tabs and role-specific work icon.
---

Keep the main mobile tabs visually consistent: a compact navy Worky header, one shared warm background, and text/icons with clear contrast. The client Trabajos tab uses a plus icon for posting; the professional Changas tab keeps a briefcase icon.

**Why:** The user explicitly requested one consistent main interface across Activity, Jobs, and the other tabs, with a blue top area and legible text.

**How to apply:** Follow this direction when changing the mobile tab shell, its shared header, or role-dependent job navigation. Preserve the distinct meaning of client posting versus professional job lists.
